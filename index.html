Demandas · Lista
  1. Escreva a demanda no campo lá embaixo.
  2. Conclua marcando o círculo à esquerda da demanda.
  3. Por padrão só aparecem as em aberto. Use o filtro "Concluídas" para ver as feitas.
  4. Finalizar tudo guarda as concluídas no Histórico (abaixo da lista). Reabra com ↺ reabrir.
Demandas · Quadro
  1. Escreva a demanda no campo lá embaixo: ela entra em A fazer.
  2. Mova o card com ‹ › ou arrastando: A fazer → Fazendo → Concluído.
  3. O que está em Concluído conta como concluído na barra de progresso.
  4. Finalizar tudo guarda os concluídos no Histórico (abaixo do quadro). Reabra com ↺ reabrir e o card volta para A fazer.
Demandas · Post-its
  1. Escreva a demanda no campo lá embaixo: ela vira uma notinha.
  2. Conclua com ✓ Concluir. Ela vai para "Concluídas aguardando finalizar".
  3. Finalizar tudo manda as concluídas para o Histórico, no fim da página. Nada é apagado.
  4. Reabra uma nota (↺ Reabrir) ou o grupo todo (↺ Reabrir todas).
